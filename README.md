# Brann's Dungeon Survival Manual

Brann's Dungeon Survival Manual (BDSM) is a small World of Warcraft Retail addon
for learning dungeons. It puts numbered tip markers on the map and on the minimap. 
Hover a marker for a short “what do I do here?” explanation. Following the 
numbered markers in order shows a recommended route through the dungeon.

So far the addon supports the Dragonflight dungeons as they have followers support
and are therefore suitable for testing, but the plan is to expand to all dungeons.

## Installation

Unzip the archive into your `Interface/AddOns/` folder.

## Usage

1. Enter a supported dungeon and open the world map with **M**.
2. Hover numbered markers for tips; the same nearby markers appear on the
   minimap.

Commands:

- `/bdsm` opens addon options

The addon follows the current dungeon floor automatically and stays hidden
outside supported party instances.
